# Čeština / English — how translations work

The app is bilingual. There are no `/en/...` URLs: the language lives in the `pp_locale`
cookie (`cs` | `en`), set by the CZ/EN switcher. Without a cookie, Czech/Slovak browsers get
Czech and everyone else English. Default is Czech.

Texts are written **inline as pairs** — Czech first, English second — so a screen is always
translated in the same place it is written.

## Client components (`'use client'`)

```tsx
import { useLocale } from '@/components/LocaleProvider';

const { t, locale, intl, plural } = useLocale();   // top of the component, before any early return

<Button>{t('Uložit', 'Save')}</Button>
alert(t('Nepodařilo se uložit.', 'Could not save.'));
date.toLocaleDateString(intl, { day: 'numeric', month: 'long' })      // was 'cs-CZ'
plural(n, ['kniha', 'knihy', 'knih'], ['book', 'books'])
safeFormatDate(value, undefined, locale)                              // from '@/lib/date'
```

Module-level arrays with labels (outside components) hold `{ cs, en }` objects (type `L10n`
from `@/lib/i18n`) and are rendered with `t(item.label)`.

## Server components (no `'use client'`)

```tsx
import { getServerLocale } from '@/lib/i18n-server';
import { tr } from '@/lib/i18n';

const locale = await getServerLocale();
<h1>{tr(locale, 'Vítejte', 'Welcome')}</h1>
```

## API routes

```ts
import { requestT, getRequestLocale } from '@/lib/i18n-server';

const t = requestT(request);
return NextResponse.json({ message: t('Neautorizováno', 'Unauthorized') }, { status: 401 });
```

## Bilingual data

| Data | Shape | Use |
|---|---|---|
| `BADGES` (`@/lib/badges`) | `name`, `tagline`, `praise`, `article` are `L10n` | `t(badge.name)` |
| `ACHIEVEMENTS`, `TRACKS` (`@/lib/achievements`) | `name`, `praise`, `label` are `L10n`; `unit(n, locale)` | `t(a.name)`, `TRACKS[x].unit(n, locale)` |
| `SECURITY_QUESTIONS` (`@/lib/security-questions`) | `L10n[]` | `t(q)`, `questionLabel(index, customText, locale)` |
| `PREDEFINED_CATEGORIES` (`@/types`) | `name` is `L10n` | new accounts get names in their language |
| `draftTimeLabel(savedAt, locale)` (`@/lib/drafts`) | | |
